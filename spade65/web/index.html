How profile applying works

Nothing is selected by default. Choose only the parts to write. A keymap write follows the official transaction: it reapplies the lighting selected in the Lighting editor and the debounce shown in Settings. Built-in controls select that effect; editing per-key colors selects the custom palette. Successful writes are saved as the profile's active snapshots.

Safety and scope
This application supports descriptor-validated configuration writes. Firmware flashing, bootloader access, raw flash, and arbitrary HID packets are intentionally disabled.

      
Privacy
The application runs locally, stores profiles locally, and does not include telemetry or automatic update installation.
