Firmware / bootloader / raw flash

Disabled for safety

No backend route or packet builder exists for these operations because no verified recovery procedure exists. Importing a profile cannot contain arbitrary HID packets.

Linux background service

Application associations and AP/timeline playback after closing the GUI are provided by the dependency-free CLI service.

spade65ctl service example ~/.config/spade65/default.json
spade65ctl service run ~/.config/spade65/default.json

Automatic keymap writes require both allow_profile_writes in the config and the explicit --allow-profile-writes command flag. A systemd user unit template is included under contrib/systemd.
